# Численные методы: интерполяция, сплайны, интегрирование и дифференцирование

Набор MATLAB/Octave-скриптов реализует несколько численных методов и содержит эксперименты для оценки погрешности приближений.

## Реализованные возможности

### 1. Интерполяция полиномом Лагранжа

Файл `lagrange.m` строит коэффициенты интерполяционного полинома по узлам `x` и значениям функции `y`.

- Формирует базисные полиномы Лагранжа.
- Складывает их с весами, заданными значениями `y(i)`.
- Использует собственную функцию умножения полиномов `my_conv`.

### 2. Интерполяция по формуле Ньютона

Файл `newtone.m` формирует коэффициенты интерполяционного полинома Ньютона для равноотстоящих узлов.

- Использует последовательные конечные разности значений функции.
- Формирует полиномиальные множители через свёртку коэффициентов.
- В реализации шаг сетки определяется как `X(2)-X(1)`, поэтому предполагается равномерное расположение узлов.

### 3. Собственные операции с полиномами

- `my_conv.m` — собственная реализация свёртки коэффициентов двух полиномов, соответствующая их умножению.
- `my_polyval.m` — вычисляет значения полинома для заданных точек, суммируя степени аргумента. В представленной версии эта функция не используется в основном сценарии.
- В скриптах также вызывается MATLAB-функция `polyval` для вычисления значений полинома.

### 4. Оценка максимального отклонения

Файл `max_deviation.m` сравнивает два массива значений одинаковой длины и возвращает вектор из трёх элементов:

1. Максимальная абсолютная разность между приближением и эталонными значениями.
2. Координата `X`, в которой найдено максимальное отклонение.
3. Значение приближающего полинома в этой точке.

Функция используется в экспериментах по интерполяции, сплайнам и численному дифференцированию.

### 5. Кубические сплайны

Файл `qubic_spline.m` содержит функции для построения и исследования кубических сплайнов.

- `calculate_spline` вычисляет коэффициенты кубического полинома на каждом интервале.
- `calculate_delta` формирует массив последовательных разностей.
- `calculate_coef` строит матрицу коэффициентов для решения системы.
- `deviation` исследует максимальную ошибку приближения при изменении числа узлов и строит график зависимости ошибки.
- `zavod` предназначена для пошагового отображения сплайнового приближения и сравнения с функцией `sin`.

В основном фрагменте файла запускается исследование `deviation(1,10,@sin,100)`. Построение сплайна и пошаговая визуализация в начале файла закомментированы.

### 6. Численное дифференцирование и агрегаты

Файл `agregats.m` реализует несколько формул приближённого вычисления производной по табличным значениям функции:

- `I1_agregat` — разностная формула первого порядка на соседних узлах.
- `II1_agregat` — односторонняя разностная формула.
- `II2_agregat` — центральная разностная формула.
- `III_agregat` и `IV_agregat` — дополнительные разностные формулы с более широким шаблоном узлов.

Функция `constants` вычисляет максимальное отклонение и оценивает показатели зависимости ошибки от шага сетки. Функция `dynamic` повторяет вычисления при разных значениях шага и строит графики погрешности.

В начале `agregats.m` задан эксперимент на интервале от `0` до `3` с функциями `sin` и `cos` и вызовом `IV_agregat`.

### 7. Узлы Чебышёва и исследование интерполяции

Файл `chebyshov_deviation.m` содержит функции для построения узлов Чебышёва и сравнения интерполяции на разных сетках.

- `chebyshov_roots` вычисляет узлы по косинусной формуле.
- `chebyshov_poly` пытается получить узлы через корни полинома.
- `chebyshov_nodes` переносит узлы с `[-1,1]` на интервал `[a,b]`.
- `deviation_dynamic` исследует изменение ошибки при увеличении числа узлов и позволяет выбрать вариант `cheb` или `ravn`.

Основной сценарий строит полином Лагранжа для функции `sin` на интервале `[1,20]`, используя 15 узлов, полученных через `chebyshov_nodes(...,"cos")`, а затем рассчитывает и отображает максимальное отклонение.

### 8. Численное интегрирование и полиномы Лежандра

Файл `integration.m` содержит функции для построения полиномов Лежандра и вычисления интеграла по узлам и весам.

- `lejandr_recur` — рекуррентное построение коэффициентов полиномов.
- `lejandr_diff` — формирование коэффициентов производной полинома через операции над коэффициентами.
- `lejandr_ortog` — построение полиномов с использованием интегральных соотношений.
- `coeff_Ak` — вычисление узлов и весов для заданного интервала.
- `interpolation_integral` — приближённое вычисление интеграла как взвешенной суммы значений функции.
- `dynamic_interpolation` — исследование ошибки интегрирования при изменении числа узлов с построением графика.

В начале файла вызывается `dynamic_interpolation(9)`. В эксперименте интеграл функции `sin` на `[1,10]` сравнивается с эталонным значением `cos(1)-cos(10)`.

### 9. Основной сценарий проверки полинома Ньютона

Файл `main.m`:

- задаёт узлы `x = 1:5`;
- вычисляет значения `sin(x)`;
- строит полином с помощью `newtone`;
- вычисляет значения полинома на более плотной сетке;
- сравнивает приближение с `sin(X)` через `max_deviation`;
- выводит максимальное отклонение и строит график приближения вместе с исходной функцией.

### 10. Резервный файл

`cus_conv.asv` — файл автосохранения MATLAB. Его содержимое не анализировалось в этом README, поэтому отдельные функции и назначение этого файла не описываются.

## Структура файлов

| Файл | Назначение |
|---|---|
| `main.m` | Демонстрация интерполяции Ньютона и оценка максимальной ошибки |
| `lagrange.m` | Построение полинома Лагранжа |
| `newtone.m` | Построение полинома Ньютона для равноотстоящих узлов |
| `my_conv.m` | Собственная свёртка коэффициентов полиномов |
| `my_polyval.m` | Собственное вычисление значений полинома |
| `max_deviation.m` | Поиск максимального абсолютного отклонения |
| `qubic_spline.m` | Построение кубических сплайнов и анализ погрешности |
| `agregats.m` | Разностные формулы численного дифференцирования |
| `chebyshov_deviation.m` | Узлы Чебышёва и анализ ошибки интерполяции |
| `integration.m` | Полиномы Лежандра и приближённое интегрирование |
| `cus_conv.asv` | Файл автосохранения MATLAB; назначение содержимого отдельно не описано |

## Запуск

Проект состоит из скриптов и функций MATLAB. Откройте нужную папку в MATLAB или совместимой среде и запустите соответствующий `.m`-файл.

Для работы отдельных сценариев функции должны находиться в текущей папке или в MATLAB path. Вызовы используют стандартные функции MATLAB, в частности `conv`, `roots`, `polyval`, `plot` и операции линейной алгебры.

## Замечания

- В нескольких функциях при несовпадении размеров массивов выводится сообщение, но выполнение не всегда явно прекращается. Перед вычислениями стоит проверять размеры входных данных.
- `newtone.m` предполагает равномерную сетку узлов.
- Для `lagrange.m` узлы `x` должны быть различны, иначе в формулах возникнет деление на ноль.
- Некоторые вычисления и построения графиков зависят от корректного числа узлов и длины входных массивов.
- README описывает код в предоставленных файлах; он не подтверждает, что все сценарии успешно выполняются без ошибок.
